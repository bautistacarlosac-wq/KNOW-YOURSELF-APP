# KNOW YOURSELF APP

Aplicación web interactiva desarrollada para evaluación personal y diagnóstico de disciplina/estatus táctico.

## 🛠️ Stack Tecnológico
- **HTML5 & JavaScript ES6+** (Arquitectura Vainilla modular)
- **Tailwind CSS CDN** (Diseño responsivo y componentes UI de alto contraste)
- **Vercel** (Despliegue e infraestructura en la nube)

## 🤖 Registro de Prompts (IA Copilot Workflow)
1. **Prompt de Arquitectura:** *"Diseña la estructura lógica de una Single Page Application en JS vainilla para una app de autoevaluación táctica sin dependencias complejas."*
2. **Prompt de UI/UX:** *"Genera un layout moderno con Tailwind CSS en tema oscuro (slate-950 y acentos amber) optimizado para legibilidad y experiencia fluida."*
3. **Prompt de Refactorización:** *"Optimiza el control de estado de JS para calcular puntajes de forma limpia y renderizar vistas dinámicas."*

- **Computational Tools:** 10/10 — Uso efectivo de GitHub para versionado y Vercel para CI/CD continuo.
